## Findings

### [P3] `.btn` touch target height is ~40px

- **Location**: `style.css` — `.btn`
- **Category**: Responsive
- **Impact**: `.btn` uses `padding: 0.75rem 1.5rem` at `font-size: 0.85rem`, producing ~40px height. The filter buttons now have `min-height: 44px`, but `.btn` (back-links, "Read more", submit) does not. In practice: the submit button is full-width so tap area is generous regardless; the back-links span the header which is easy to tap. No user is blocked. Noting only for completeness.
- **WCAG**: 2.5.5 Target Size — Level AA
- **Recommendation**: Add `min-height: 44px` to `.btn` for consistency.
- **Suggested command**: `/impeccable adapt`

## Positive Findings

1. **All contrast pairs verified at ≥4.5:1.** The two-token accent split (`--accent` for surfaces, `--accent-text` for foreground text) is working correctly. Bumping `--accent` to `#d62b1a` raised white-on-btn from 4.52:1 to 4.98:1.

2. **Touch targets resolved.** Filter buttons now have `min-height: 44px`. Form inputs have `min-height: 44px`. These were the primary mobile usability gap.

3. **Source links are screen-reader navigable.** `aria-label="Source article for ${name}"` on each entry's source link disambiguates the repeated "Source ↗" text. Keyboard users navigating links by tab or screen reader now hear distinct labels per card.

4. **Em dashes eliminated everywhere.** Swept from all HTML, CSS, JS, MD, and JSON files including the rendered `_entries.json` data layer. Zero occurrences in any file the site reads or ships.

5. **Security posture is correct.** `escapeHtml()` on all entry fields; `safeUrl()` rejecting non-http(s) sources; querySelector try-caught against URL param injection.

6. **Animation is compositor-safe.** `fadeIn` uses only `opacity` and `transform`. Guarded by `prefers-reduced-motion: no-preference` wrapper. Stagger at 40ms/card is tight and purposeful.

7. **Token system is watertight.** Zero hard-coded color values in `style.css`. DESIGN.md frontmatter reflects the updated `--accent` value.

8. **Anti-pattern score is clean.** The detector finds zero real issues across three HTML pages. The site is genuinely distinctive — not generic.
