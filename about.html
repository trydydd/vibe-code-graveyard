What is this?

The Vibe Code Graveyard tracks startups, apps, and projects built with AI coding tools (Cursor, Claude Code, Bolt.new, Lovable, v0) that are already experiencing public failures.

Crashes, security breaches, scaling meltdowns, abandoned projects, founder confessions of regret.

How entries are sourced

Every entry comes from publicly available information: Reddit threads, Hacker News comments, IndieHackers posts, Product Hunt comments, and Twitter/X posts. Nothing here goes beyond what founders chose to share publicly.

Status tags

Active Still running, still breaking
Abandoned Shut down or abandoned
Fixing Currently being cleaned up
Fixed Actually survived the cleanup

Why does this exist?

Because AI coding tools are producing real technical debt at scale, and nobody's keeping score. This isn't about shaming founders; it's about documenting the pattern so the next person doesn't walk into the same hole.
